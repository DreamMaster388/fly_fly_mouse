# Spec

1. 读 `docs/sdlc/<分支>/intent.md`（须已批准），背景只引用不复述。
2. `AGENTS.md` 存在时当硬约束。
3. 照模板写，≤ 60 行；只写做法，不写签名、不写用例。
4. 交付前删一遍：能留给 plan 的，删。
5. 用户确认后标「已批准」。

## 模板（照这个长度）

```markdown
# Spec: 理赔进度自助查询（来自 intent.md）
作者：lyd。状态：草稿。

一句话：门户展示进度、下一步与预计日期，只读。

## 需求
R1 进度接口只读，写操作返回 405。
R2 响应不含 PII 字段。
R3 上游超时 3 秒内降级为空状态。

## 风险与分歧
C1 公估人是否可见 → 已定：本期不可见（产品负责人）。

## 设计
复用网关 JWT；ResultPanel 直连接口，缓存 30 秒。

## 不在范围
- 短信通知。

下一步：/sdlc-plan
```
