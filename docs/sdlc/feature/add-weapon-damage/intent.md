# Intent: 武器伤害与僵尸死亡
作者：lyd。状态：已批准。

## 问题
飞镖阵型已有碰撞体但只做跟随与公转，接触僵尸没有任何结果；僵尸无限追人且无法被消灭，玩家没有输出手段，战斗闭环缺失。`ZombieDie.gif` 素材已就位但游戏未使用，且当前武器与僵尸均为单一硬编码实现，后续扩展种类成本高。

## 预期结果
飞镖接触僵尸即判定伤害：同一帧内与飞镖碰撞体重叠的所有僵尸各扣 1 点，随后该飞镖消失，一枚飞镖只结算一次。僵尸受伤当帧整体变红约 120ms 后恢复，同一帧多次命中只闪一次。僵尸血量 10，归零后停止移动、退出所有碰撞与受伤判定，原地播放一次死亡动画（ZombieDie.gif）后销毁，死亡期间不占“场上最多 5 只”名额。被消耗的飞镖每 1 秒补充 1 枚，上限 8 枚，直接在对应轨道槽位出现并继续公转/自转。僵尸受伤时播放 splat1，致死的一击只播放 splat3，每次事件独立实例、多只可同时播放；碰到角色被销毁时不播音效。

## 影响面
`src/WeaponOrbit.js`（槽位化、命中消耗、补充计时）、新增飞镖-僵尸碰撞判定（可挂在飞镖阵型或独立模块）、`src/Zombie.js`（血量、受击闪烁、死亡流程）、`src/ZombieManager.js`（受伤与死亡接入、计数规则）、`src/WorldScene.js`（加载并注册死亡动画帧）、新增武器/僵尸配置模块、死亡动画预拆 spritesheet 与 `resource/audio/` 音效资源（`.gitignore` 放行 mp3）；不改主角移动、相机、僵尸生成规则与追踪。

## 约束
- 伤害单元：1 枚飞镖 = 1 点伤害；对接触瞬间所有重叠僵尸各生效一次，之后飞镖立即销毁，不穿透、不重复命中、未命中则不消失。
- 判定范围沿用飞镖现有圆形碰撞体，不额外扩大；不做伤害 tick/DOT、暴击、击退。
- 僵尸固定血量 10，唯一受伤来源为飞镖；一帧内可被多枚飞镖叠加伤害，血量 ≤ 0 即死亡。
- 受击反馈：受伤当帧整体变红约 120ms 后恢复，同一帧多次命中只闪一次；当帧死亡则直接进入死亡动画，不额外闪烁。
- 死亡流程：血量归零当帧停速、关闭本体碰撞并退出“飞镖命中 / 角色接触”判定，播完死亡动画再销毁；不占 5 只存活上限。
- 死亡动画使用 `resource/Plants-vs-zombies/663/images/Zombies/Zombie/ZombieDie.gif`（与外部给到的路径为同一文件），按行走动画同样方式用 sharp 预拆横向 spritesheet，运行时用 Phaser 动画播放，不新增依赖、不在运行时解码 GIF。
- 音效：受伤播 splat1、致死播 splat3，致死一击不再叠播 splat1；每次事件新建独立实例，多只僵尸互不打断；接触销毁静音；mp3 复制到 `resource/audio/` 经 Vite URL 加载，不新增依赖。
- 可维护性：武器与僵尸的数值（伤害、血量、移速、数量上限、补充间隔等）、贴图与动画声明集中到配置；受击统一走受击接口（如 takeDamage(amount)），碰撞回调不写死武器或僵尸类型；新增种类以扩展配置/小类为主，不改伤害结算与死亡流程。
- 补给：每 1 秒补 1 枚，最多 8 枚；仅在有空格时补充，槽满不累积；补充直接出现在槽位，无飞入动画。
- 僵尸碰到角色维持现状：僵尸消失、`onReachPlayer` 保持空实现。
- 沿用 Phaser 4 + Vite 与现有 Arcade 物理。

## 未定

- 武器/僵尸配置的字段清单与新增一种类型的最小扩展步骤，在 spec 定。
- 死亡动画期间是否沿用原朝向镜像，按与行走动画一致处理；帧数与时长在 spec 按实际 GIF 确认。
- 多只僵尸同时受击的叠加音量待实机确认，必要时调低默认音量。
