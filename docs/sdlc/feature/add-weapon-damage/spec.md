# Spec: 武器伤害与僵尸死亡（来自 intent.md）
作者：lyd。状态：已批准。

一句话：飞镖按碰撞体群伤并消耗，僵尸 10 血、受击变红与音效、死亡动画播完销毁，飞镖每秒补 1 枚。

## 需求
R1 配置驱动：新增集中配置，按类型声明武器（伤害、槽位数、补充间隔、轨道半径与转速、显示尺寸、贴图）与僵尸（血量、移速、刷新间隔、存活上限、显示尺寸、行走/死亡 spritesheet、帧数与帧时长、碰撞体几何）；场景按配置加载资源，模块按类型 id 取参数。
R2 伤害结算：飞镖与存活僵尸重叠即命中；每个飞镖在同一物理帧内对所有重叠僵尸各造成 1 点伤害，随后该飞镖销毁；未重叠不消耗，已销毁的飞镖不再参与任何结算。
R3 结算顺序：以飞镖为单位集中结算——先收集该飞镖当前重合的存活僵尸，统一扣血后再移除飞镖；不依赖逐对回调顺序，确保同一飞镖不重复命中，同帧多枚飞镖对同一僵尸可叠加。
R4 槽位：阵型固定 8 个角度槽位；飞镖消耗后对应槽位为空，空槽不渲染、无碰撞体；公转与自转仍按全局时间计算，补充后位置与角度连续。
R5 补充：每 1000ms 检查一次，有空槽则按槽位序号游标取下一个空槽补 1 枚；补满 8 枚即停，不累积欠额；补充直接在槽位出现，无飞入动画。
R6 血量：僵尸固定 10 点血，唯一伤害来源为飞镖；血量降到 0 及以下即死亡，已死亡僵尸忽略后续伤害。
R7 受击反馈：受伤当帧整体染红约 120ms 后恢复原色；闪烁期间再次受伤不重新计时；当帧死亡则直接进入死亡流程，不再闪烁。
R8 死亡：死亡当帧速度归零、碰撞体关闭、立即退出命中与角色接触判定，并立即释放存活名额；死亡动画只播一次，播完销毁。
R9 死亡动画：沿用原 GIF 的 10 帧、每帧 166×144，帧时长依次为 100、100、200、100、100、100、100、100、100、1000ms（总 2000ms），末帧停留后销毁。
R10 资源：开发期用 sharp 将 ZombieDie.gif 预拆为横向 spritesheet（每帧 166×144），产物存为 `resource/enemy/zombie-die-spritesheet.png` 并经 Vite URL 加载；运行时不解码 GIF、不新增依赖。
R11 朝向：死亡动画沿用死亡前的镜像朝向，死亡后不再随移动翻转。
R12 角色接触：维持现状——僵尸与角色重叠即直接销毁并调用空回调，不结算血量、不播死亡动画；死亡中的僵尸不参与该判定。
R13 不变：主角移动与镜像、相机、地图、僵尸刷新规则、追踪速度与行走动画均不改。
R14 音效：僵尸受伤播放 splat1（zombie-hit），致死的一击只播放 splat3（zombie-die）；每次事件新建独立音频实例，多只僵尸可同时播放互不打断；角色接触销毁不播音效；两条 mp3 复制到 `resource/audio/` 并经 Vite URL 加载，不新增依赖。

## 风险与分歧
C1 判定范围沿用现有飞镖圆形碰撞体（显示高 27px，等效半径约 9.5px），不额外扩大；若手感偏弱后续再调。
C2 补充按槽位序号轮转（intent 未定项已定），补充顺序沿轨道推进，不随机。
C3 死亡动画总时长 2 秒且不占刷新名额；击杀密集时可能短暂出现多只死亡动画，不额外限流。
C4 本期不建武器/僵尸基类与类型注册表，以配置加少量行为钩子实现扩展；新增类型只加配置、资源与必要的差异化行为。
C5 受击染红作用于整张贴图，与僵尸原有配色叠加后的观感以实机为准。
C6 群伤按同一时刻的重叠集合计算；高速公转下相邻帧的命中差异可接受，不做事前扫掠检测。
C7 浏览器音频需首次用户交互解锁；多只僵尸同时受击会叠加音量，默认 1.0，必要时后续调低。

## 设计
- 新增 `src/config.js`，导出武器与僵尸的类型表；现有数量、速度、尺寸、帧时序等常量迁入配置，旧模块按类型 id 读取。
- `WeaponOrbit` 改为槽位模型：8 个槽各存飞镖实例或空；每帧按全局公转角计算活动飞镖位置与自转，并驱动补充计时与槽位游标。
- 新增战斗结算模块：每帧遍历活动飞镖，用 Arcade 重叠检测收集重合的存活僵尸，统一调用僵尸受击入口后销毁飞镖；在场景中注册。
- `Zombie` 增加血量、死亡标记、受伤染色计时与死亡动画播放；`ZombieManager` 的存活集合在死亡当帧移除，供刷新上限与战斗结算共用。
- `WorldScene` 的 preload 遍历配置加载武器贴图、行走与死亡 spritesheet 以及两条音效；create 按类型 id 创建阵型、僵尸与战斗模块，update 顺序为角色→武器→僵尸→结算。
- 受击与死亡音效通过场景声音系统新建实例播放，不共用单一音源；致死路径跳过受击音，接触销毁路径不触发音频。
- 死亡 spritesheet 由一次性 sharp 脚本生成并入库；运行时代码只加载 PNG。

## 不在范围
- 玩家受伤/死亡、僵尸攻击动画与伤害、击退、无敌帧。
- 伤害数字、僵尸血条与击杀特效、音量设置/静音开关、空间音频。
- 新增武器/僵尸类型、武器切换、掉落与拾取、存档。
- 刷新规则、追踪参数、地图与相机调整。
