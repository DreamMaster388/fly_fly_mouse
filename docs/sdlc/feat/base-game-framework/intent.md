# Intent: 开始界面与生存计分流程
作者：lyd。状态：已批准。

## 问题
打开页面直接进入世界场景，没有开始入口；僵尸碰到主角只会销毁、不扣血，游戏也没有血量、击杀计分与失败重开的闭环，玩家缺少目标与生存反馈。

## 预期结果
- 开始界面只有一个「开始游戏」按钮，点击后进入现有世界场景。
- 主角初始血量 10；僵尸碰到主角扣 1 点血并播放 chomp.mp3 音效，僵尸仍按现有逻辑销毁。
- 游戏顶部显示计时器、计分栏和数字血量（如 10/10），从点击开始进入游戏时开始计时。
- 每击杀一只僵尸加 1 分。
- 血量归零后游戏逻辑停止并弹出结算界面，显示最终分数与存活时间，以及「再来一局」按钮。
- 点击「再来一局」直接重开游戏（不回到开始界面），血量、分数、计时全部重置。
- BGM 2.75.mp3 从开始界面起全程循环播放，进入游戏、弹出结算、再来一局都不中断、不重头播放。

## 影响面
新增开始界面、游戏 HUD、结算界面与游戏状态（血量/分数/计时）；接入现有僵尸接触与死亡回调；注册场景；新增 chomp.mp3、2.75.mp3 音频资源。

## 约束
- 音频使用指定文件，复制进仓库 resource/audio/ 以适配 Vite 资源加载；BGM 必须循环且全局唯一。
- 沿用 Phaser 4 + Vite，不引入新库。
- 每只僵尸只造成 1 点伤害；不新增受击无敌帧、击退、血条动画等额外机制。
- 不改主角移动手感、相机、地图、飞镖数量，以及现有数值（僵尸 10 HP、飞镖 1 伤害、僵尸移速 150）。
- 开始界面保持最简：只有「开始游戏」按钮，不加标题、设置或其他入口。

## 未定

- 结算界面视觉样式（遮罩/面板/按钮排版）在 spec 定。
