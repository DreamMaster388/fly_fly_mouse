# Spec: 生存 180 秒与商店/难度下线

本规格取代 [difficulty-system](../difficulty-system/spec.md) 全部；部分取代 [base-game-framework](../base-game-framework/spec.md) 的计时、HUD、结算与重开条目，以及 [mob-dog](../mob-dog/spec.md) 的击杀金币奖励。开始界面、BGM、受伤、经验/升级与敌种行为继续有效。

## 问题

现在一局没有终点，计时无限上涨，玩家不知道什么时候算赢。难度段位只显示名字、不改变敌人，却占着 HUD；金币和商店把 3 分钟的单局变成经济管理，炸弹也只能靠商店获得。玩家需要一条明确的“活到 3 分钟”目标，以及只服务这条目标的界面。

## 方案

- 每局固定 180 秒：HUD 从 3:00 倒计时到 0:00，归零判胜；生命先归零判负。
- 删除难度段位、金币、商店、饰品与相关 HUD；保留经验、等级、升级点与飞镖升级。
- 底部 HUD 去掉右侧面板后整体居中。
- 蹦蹦炸弹保留实现，但玩家和开发控制台都没有获得入口。
- 结算区分胜利/失败，显示存活时间，并可再来一局。

## 用户故事

1. 作为玩家，我想看到 3:00 倒计时，以便知道离胜利还有多久。
2. 作为玩家，我想活到 0:00 就立即胜利，以便每局有明确终点。
3. 作为玩家，我想在提前死亡时看到失败和实际存活时间，以便判断差距。
4. 作为玩家，我不想再看到难度、商店、金币和空饰品栏，以便界面只服务生存目标。
5. 作为玩家，我想继续靠击杀经验升级飞镖，以便 3 分钟内仍有成长。
6. 作为测试者，我想在控制台立即判胜或判负，以便验证两条结算路径。

## 实现决策

- 单一时间源是局内已用时间，生存目标固定 180000 毫秒；倒计时显示目标减已用时间的差值，格式 m:ss，起始 3:00。场景暂停时倒计时不减少。
- 每帧推进时间后检查胜利：已用时间达到目标、生命大于 0 且本局未结束时判胜。受伤路径生命归零立即判负；同一帧两者都发生时判负，且不因时间随后达到目标而改判。
- 结束本局接受“胜利/失败”结果，首次调用生效，后续调用忽略。结算后本帧与之后都不得再推进计时或刷新 HUD；胜负都冻结刷怪、物理与 HUD，并弹同一套结算层。
- 结算层标题为“胜利”或“失败”，显示存活时间：胜利为目标时长，失败为实际值；不再显示金钱；按钮仍为“再来一局”，重开后倒计时、生命、经验与升级点全部重置。
- 难度模块、档位状态、HUD 难度文字与控制台“进入下一难度”删除，不新增任何敌压成长；刷怪节拍、人口上限、狗/蝗虫/僵尸的出现概率与属性保持现状。
- 商店场景与注册、金币状态、金币入口与结算金钱、金币奖励、饰品/红宝石及饰品栏全部删除。所有敌人击杀奖励只保留经验（普通僵尸 60、蝗虫 30、狗 400）。
- 初始配装仍只有飞镖；六个武器槽、经验环、等级徽章、升级按钮保留。底部 HUD 删除右侧金币/饰品面板，主信息条与内容整体水平居中。
- 蹦蹦炸弹的配置、实现、动画/爆炸资源与内部挂载入口保留；不提供商店、控制台或任何玩家入口，其购买价格等商店元数据删除。
- 控制台删除金币与难度按钮，保留刷怪、清场、生命锁定、回血、经验与结束本局；“结束本局”按失败结算；新增“立即胜利”，将本局时间置为生存目标后按胜利结算。

## 测试决策

- 唯一 seam：真实浏览器 + Vite + `window.game`，复用现有验收 harness，从世界场景读取 HUD、场景列表、局内状态与结算层。不新增单元 seam。
- 起始与界面：进入世界后倒计时为 3:00；场景列表只有开始与世界；HUD 不存在难度、金币、饰品栏元素；主信息条水平居中；配装只有飞镖。
- 胜利：把局内时间设到目标前一帧，断言倒计时只剩 1 秒；越过目标后断言本局结束、标题“胜利”、倒计时归零、刷怪停止、物理暂停，且存活时间等于目标时长。
- 失败：目标前造成致命伤，断言标题“失败”与实际存活时间；随后模拟时间越过目标，断言仍为失败、不翻盘。
- 重开：从胜/负结算点“再来一局”，断言倒计时回到起点、生命/经验/升级点重置、旧结算消失。
- 炸弹：经内部挂载入口直接挂载，断言炸弹按配置投掷并造成爆炸伤害；断言控制台与 HUD 都没有炸弹入口。
- 旧用例：难度、items-shop、shop-catalog 套件删除；炸弹套件改为直接挂载；base-flow 与 hud-rewards 按新规则改写。不测已删除的商店/难度内部、颜色字体像素细节、真实等待 180 秒、胜负音效与存档。

## 不在范围

- 给炸弹补新的获得方式。
- 随时间变化的敌压或新的难度曲线。
- 击杀数、分数、最高分与存档。
- 胜利/失败专属音效或 BGM 变化。
- 手机与触屏适配。

## 补充说明

- 已知限制：立即胜利会把局内时间写成生存目标，因此结算恒显示目标时长；这是调试入口，不是正常玩法。
