# 02: 生存 180 秒：倒计时与胜负结算

**要构建什么：** 每局从 3:00 开始倒计时；归零且存活即胜利，提前死亡即失败；同帧死亡优先判负；结算显示胜负与存活时间，并可重开。

**阻塞于：** 无（可立即开始）

**状态：** ready-for-agent

- [ ] 世界场景启动显示 3:00 倒计时，随后随游戏时间减少；场景暂停时倒计时不减少。
- [ ] 倒计时归零且生命大于 0 时本局以胜利结束；生命在归零前降至 0 时以失败结束。
- [ ] 同一帧内生命归零与时间归零同时发生时结算为失败；结束后即使时间越过目标也不翻成胜利。
- [ ] 结算层显示“胜利”或“失败”标题与存活时间，胜利为目标时长、失败为实际时长，不再显示金钱，并提供“再来一局”。
- [ ] 结算后计时、HUD、刷怪与物理全部冻结，后续时间推进不改变结果；重开后倒计时、生命、经验与升级点重置。
- [ ] 控制台“结束本局”按失败结算；新增“立即胜利”，把本局时间置为目标后按胜利结算。
- [ ] 验收覆盖胜利、失败、同帧优先、冻结与重开路径；通过把局内时间设到目标前一帧来验证，不真实等待 180 秒。
