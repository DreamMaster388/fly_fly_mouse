# Intent: 镜头外刷新追踪僵尸
作者：lyd。状态：已批准。

## 问题
世界地图 2000×2000、镜头 1280×720 跟随主角，场景里除了参照点和环绕飞镖没有任何威胁；`resource/Plants-vs-zombies/663/images/Zombies/Zombie/Zombie.gif` 素材已就位但游戏未使用，后续战斗逻辑也没有可挂接的对象。

## 预期结果
新增怪物刷新模块：在地图内、镜头外的区域周期生成僵尸，每约 2 秒尝试刷 1 只、场上最多 5 只。僵尸以主角一半移速（150，主角为 300）持续朝主角移动，移动中循环播放行走帧动画，并按水平移动方向左右镜像（原始动画朝左）。碰到主角时僵尸消失，接触逻辑先留空回调点。本期只有僵尸一种怪，仅具备移速属性，显示高约 110px，与主角同级。

## 影响面
`src/WorldScene.js`（加载贴图、创建怪物模块）、新增怪物模块（属性、生成规则、追踪、动画、接触回调）、新增预拆帧 spritesheet 资源；不改主角移动手感、相机、地图与飞镖。

## 约束
- 使用指定 Zombie.gif（166×144、约 22 帧）；开发期用已有 sharp 预拆成横向 PNG spritesheet，运行时用 Phaser 动画播放，不新增运行时依赖、不在运行时解码 GIF。
- 生成点必须在地图边界内、相机视野外，位置随机；不改地图与相机尺寸。
- 移速固定为主角一半 = 150，作为怪物属性定义，便于后续多怪配置；本期不做随机化。
- 镜像只影响怪物自身；水平速度趋近 0 时保持上一次朝向。
- 接触表现为怪物销毁，回调点留空；伤害、击退、音效本版不做。
- 沿用 Phaser 4 + Vite，生成与追踪用现有 Arcade 物理，不引入新库。

## 未定
- 生成点距镜头边缘的余量（避免刚刷出就入镜的突兀感），在 spec 定具体数值。
- 多只怪之间是否互相碰撞或避让，本版不处理。
- 接触后的正式逻辑（伤害、击退、玩家死亡等）待后续需求。
