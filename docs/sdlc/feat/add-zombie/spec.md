# Spec: 镜头外刷新追踪僵尸（来自 intent.md）
作者：lyd。状态：已批准。

一句话：地图内、镜头外周期刷新僵尸，以主角一半速度追踪并循环行走动画，接触主角后消失，接触逻辑留空。

## 需求
R1 贴图：用项目内 sharp 预拆 Zombie.gif（22 帧、每帧 166×144），生成横向 spritesheet PNG 存于 `resource/enemy/zombie-walk-spritesheet.png`，经 Vite URL 导入加载；运行时不解析 GIF、不新增依赖。
R2 动画：22 帧循环，帧延迟沿用原 GIF 的 90/180ms 交替（整轮约 2.97 秒）；僵尸存活期间持续播放行走动画。
R3 生成：场景创建后立即首刷，此后每 2000ms 尝试一次；场上存活达 5 只时跳过本次，不排队。
R4 生成位置：地图边界内随机取点，且完全在镜头外（距当前相机可视矩形至少 80px）；找不到合法点则跳过本次刷新。
R5 追踪：每帧朝主角当前显示中心方向归一化后施加速度，恒定 150px/s（主角 300 的一半）；主角移动时方向实时更新。
R6 属性：怪物配置只含移速一项（150）；显示尺寸与动画参数作为模块常量，不在实例上做差异化。
R7 镜像：原始动画朝左；水平速度 vx<0 保持默认朝向，vx>0 水平翻转，|vx|<1 时保持上一次朝向。
R8 显示：等比缩放至显示高 110px（宽约 127px），不变形；怪物渲染层级低于主角与飞镖。
R9 接触：僵尸圆形 body 与主角 body 重叠即销毁该僵尸，并调用一个空的接触回调入口；本版无伤害、击退、音效。
R10 物理：僵尸 body 为圆形，按显示尺寸比例覆盖身体，纳入现有 Arcade 物理世界；不注册僵尸之间的碰撞。

## 风险与分歧
C1 接触回调只留空入口，正式效果（伤害/击退/玩家死亡）待后续需求。
C2 生成点按地图全域随机筛选，不按四边固定分布；80px 余量可随观感调整。
C3 怪物层级低于主角与飞镖，不做 Y 轴深度排序；多怪重叠不做避让（对应 intent 未定项）。
C4 仅提交拆帧后的 spritesheet PNG；Zombie.gif 源文件保持本地不入库（已定：需要时本地重新拆帧）。

## 设计
- 新增 `src/ZombieManager.js`：负责 spritesheet 加载、动画注册、定时生成，以及每帧追踪、镜像与接触回调；`WorldScene` 在 preload 加载贴图、create 创建管理器、update 中更新。
- 生成间隔按场景累计时间判断；存活数由管理器维护，达上限只跳过本次，不堆积待生成。
- 追踪每帧重算朝向主角的向量并写入 body 速度；接触用 Arcade overlap 检测主角与僵尸，命中后销毁僵尸并调用空回调。
- 拆帧由开发期一次性脚本完成，产物 PNG 入库；生产构建不包含 GIF 解码逻辑。
- 沿用现有 Vite 资源导入与 Arcade 物理，不改主角、相机、地图和飞镖逻辑。

## 不在范围
- 伤害、击退、玩家死亡/无敌、音效与命中特效。
- 多怪种、刷新参数配置化、怪物间碰撞与避让。
- 怪物攻击动画、死亡动画（BoomDie.gif 等）与击杀奖励。
