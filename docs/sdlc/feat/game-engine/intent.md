# Intent: 2D 游戏基础——黑圆在大地图上按键盘移动
作者：lyd。状态：已批准。

## 问题
仓库现在只有角色 PNG 和 SDLC 说明，没有能跑起来的东西。玩法、素材、部署都还无从挂接。

## 预期结果
浏览器打开公网链接，白底上有个黑色圆，方向键（WASD 同效）按哪走哪、松手即停。地图比屏幕大，相机跟随圆并在地图边缘钳住；圆到地图边界停住。地基（引擎、循环、输入、地图、相机、部署）一次跑通，后续需求都叠在这上面。

## 影响面
新增游戏代码与构建配置；`.gitignore` 白名单要放行源码和构建产物；`resource/` 素材本期只用 Phaser 自带图形，不加载 PNG。

## 验收
运动跟手不卡帧；圆不超出地图边界；屏幕外区域能靠走位看到；公网链接别人点开即玩无报错；换 PNG 不必推翻重做。

## 约束
Phaser 4（原选 Phaser 3，因 v3 止于 3.90.0 且不再有新功能，2026-11-08 改定），不自研渲染循环；构建用 Vite；纯前端、无后端无账号；本期 PC 浏览器加键盘，触屏与桌面悬浮窗不做；黑圆是占位，要为后期换 `resource/` 分层 PNG 留位置；地图尺寸为固定常量（初值 2000x2000）；相机跟随角色并在地图边缘钳位；部署走 Qoder Sites。

## 未定
素材与构建产物的体积上限（Qoder Sites 侧）；浏览器最低版本；是否要一键重置初始位置；地图常量后续是否要进配置文件。已定：画布 1280x720 + Scale.FIT。
