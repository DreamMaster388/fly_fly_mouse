# Spec: 2D 游戏基础——黑圆在大地图上按键盘移动（来自 intent.md）
作者：lyd。状态：已批准。

一句话：Phaser 4 + Vite，键盘控制黑圆在 2000x2000 地图上直接位移、相机跟随并钳位，构建产物部署到 Qoder Sites。

## 需求
R1 工具链为 Vite + npm 依赖 phaser@^4.1，纯 JS 不引入 TypeScript，无后端、无账号、无存档。
R2 画布基准 1280x720 用 Scale.FIT 缩放；游戏世界固定 2000x2000，与画布尺寸解耦。
R3 方向键与 WASD 均可控制，按下即动、松手即停、无惯性；斜向合成后速度不大于直线，位移按 delta 时间换算，不随帧率变化。
R4 圆不能越过地图边界：贴边停住，不出现半出图，世界坐标不无限增长。
R5 相机 1:1 跟随圆、不缩放；推到地图边缘时钳住不再前进，屏幕内不露出地图外的空区。
R6 角色为白底上的黑色圆，运行时用引擎自带图形生成，不加载 `resource/` 任何 PNG，页面加载期无网络请求与控制台报错。
R7 角色独立成模块，对外只暴露位置、输入处理与每帧更新；后期换 `resource/` 分层 PNG 只替换该模块内部实现，不改世界、相机与输入。
R8 帧循环交给引擎；移动逻辑每帧不创建新对象，目标桌面 Chrome 60fps 无可感知卡顿，开发期用引擎自带 FPS 面板核对。
R9 交付静态产物（Vite 构建输出），可由 Qoder Sites 直接托管他人打开链接即玩；部署子路径导致资源 404 的情况要处理。

## 风险与分歧
C1 引擎版本 → 已定：Phaser 4.x。v3 止于 3.90.0 且官方不再加新功能，新项目无迁移成本（用户 2026-11-08 确认）。
C2 画布与缩放 → 已定：1280x720 + FIT。非 16:9 窗口时画布外留黑边（黑边在画布之外，不遮住世界），好处是世界可见范围不随窗口大小变化。
C3 触屏 → 已定：本期不做，手机打开无法操作；体积上限仍属未定。

## 设计
`index.html` + `src/` 两个职责：场景只做世界搭建（背景、地图尺寸、相机跟随）；`Player` 模块自包含黑色圆的创建、键盘输入、位移与边界钳制，R7 的替换点就落在这里。地图尺寸先写成模块常量，是否进配置留待后续。

## 不在范围
PNG 角色与分层动画、音效、玩法与关卡、触屏、TypeScript 接入、桌面悬浮窗形态、存档与统计。
