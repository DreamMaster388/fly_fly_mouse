# Spec: 角色周围八向飞镖环绕（来自 intent.md）
作者：lyd。状态：已批准。

一句话：8 支飞镖等距环绕角色，整体顺时针公转，单支顺时针自转，刚性跟随角色位置。

## 需求
R1 场景通过 Vite 资源导入加载 `resource/weapon/武器-飞镖-透明.png` 作为唯一飞镖贴图。
R2 生成 8 支飞镖，角度等分 45°，初始状态一支位于正上方；轨道半径 90px，圆心取角色贴图显示中心；每支显示高度 27px、等比缩放不变形。
R3 公转顺时针 90°/秒（4 秒一圈），角位置按场景累计时间计算，帧率变化不影响转速。
R4 每支飞镖绕自身中心顺时针 360°/秒（1 秒一圈）自转，转速与公转独立，不朝向切线或径向。
R5 刚性跟随：每帧以角色当前显示中心重算阵型位置，不做缓动或延迟；角色停下时阵型相对角色静止。
R6 角色镜像翻转只作用于角色，飞镖不跟随翻转、不改变朝向。
R7 每支飞镖挂一个圆形物理 body，尺寸按显示高度比例设定；无重力、不主动移动、不注册碰撞回调、不造成伤害。
R8 飞镖渲染层级高于角色，避免被角色遮挡。

## 风险与分歧
C1 公转圆心取角色贴图显示中心（已核实可见像素居中），不取脚部物理 body 圆心，保证阵型视觉居中。
C2 公转与自转同为顺时针，叠加观感需实机确认；若眩晕再调（对应 intent 未定项）。
C3 碰撞体本期仅占位，敌人接入后再定命中、伤害与穿透规则。
C4 角色贴近地图边缘时飞镖允许伸出地图边界显示。
C5 飞镖数量、半径、转速暂为常量，不做配置化。

## 设计
- 新增 `src/WeaponOrbit.js`，封装 8 支飞镖的创建、逐帧位置与自转计算，对外提供创建与更新入口。
- `WorldScene` 在 preload 加载飞镖纹理，create 实例化阵型，update 中先更新角色再更新阵型。
- 公转位置每帧由累计时间与固定角速度经三角函数算出；每支飞镖的 rotation 单独按自转速度计算，不使用整体容器旋转，避免自转被公转方向带偏。
- 物理沿用现有 Arcade 物理世界，圆形 body 尺寸取显示高度的一半以内，关闭重力与碰撞回调。
- 飞镖贴图与玩家贴图同样用 Vite URL 导入，随构建产物发布；不引入新依赖。

## 不在范围
- 命中判定、伤害数值、飞镖回收或消耗。
- 飞镖数量/半径可配置、触屏与移动端适配。
- 角色移动手感、相机行为与地图尺寸调整。
