# 01: 狗的基础接入与接触/击杀

**要构建什么：** 新的地面精英“狗”从现有 2 秒混刷中出现（10% 狗 / 20% 蝗虫 / 70% 僵尸，同屏最多 1 只、占 3 人口），以普通走路动画走向玩家，移速 60；100 HP，受击只闪红、没有受伤状态。被武器打死奖励 200 金 / 400 经验并淡出；接触玩家造成 200 伤害后死亡淡出；两种情况都不爆炸、不留粘液。距离玩家超过 1600 时脱战清理。本票不包含嚎叫与自身激怒。

**阻塞于：** 无（可立即开始）。

**状态：** ready-for-agent

- [ ] 狗能通过正常刷怪入口出现；同屏最多 1 只、占 3 人口，人口满或无出生点时刷新失败。混刷权重按 10/20/70 配置，随机权重本身不做自动化断言。
- [ ] 狗从屏幕外出生环进入，按普通走路动画以 60 移速接近玩家；地形减速按既有倍率叠加；显示高度 120。
- [ ] 狗有 100 HP；受击闪红但不切换受伤动画或受伤状态。
- [ ] 武器击杀狗：奖励 200 金 / 400 经验，狗 0.3 秒淡出，不播放死亡动画、不爆炸、不留粘液、不播放狗专属音效。
- [ ] 普通阶段接触玩家：立即结算 200 伤害，狗死亡并淡出；不给击杀奖励、不爆炸、不留粘液；玩家生命归零时进入结算界面。
- [ ] 距离玩家超过 1600 时狗脱战消失并释放人口；小地图显示现有红色敌人点，不做特殊标识。
- [ ] 新增验收覆盖出现与上限、普通移动、武器击杀奖励、接触伤害、脱战与人口释放。
