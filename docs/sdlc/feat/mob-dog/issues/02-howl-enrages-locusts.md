# 02: 嚎叫激怒屏幕内蝗虫

**要构建什么：** 狗首次进入玩家视野满 3 秒游戏时间后站定，播放一次约 2.7 秒的嚎叫；开始瞬间把当前视野内所有普通状态蝗虫一起激怒。蝗虫不再靠自身进入视野 3 秒自动激怒。受伤、离屏、已激怒或正在激怒的蝗虫不受影响，嚎叫后刷出或进入视野的蝗虫也不受影响。狗在屏外完成计时仍会嚎叫；嚎叫开始前被击杀则不触发，开始后击杀不撤销已激怒。嚎叫期间狗仍可被击杀、接触玩家或脱战。本票结束时狗在嚎叫后回到普通走路；自身等待与激怒在 03。

**阻塞于：** 01（狗的基础接入与接触/击杀）。

**状态：** ready-for-agent

- [ ] 首次进入视野开始计 3 秒；阈值前保持普通走路；到点站定播放一次嚎叫，约 2.7 秒后结束。离开视野不暂停、不重置计时；场景暂停期间计时不推进。
- [ ] 嚎叫开始瞬间，当前视野内所有普通状态蝗虫一起进入现有激怒流程：先播激怒动画，随后按激怒行走移动。
- [ ] 受伤、离屏、已激怒或正在激怒的蝗虫不被嚎叫影响；嚎叫后刷出或进入视野的普通蝗虫也不会被这次嚎叫激怒。
- [ ] 没有狗时，普通蝗虫在视野内停留超过原 3 秒阈值仍不激怒；原有自动激怒触发被移除。
- [ ] 狗在屏外完成计时仍会嚎叫，并以当时玩家视野为准结算；每只狗只嚎叫一次。
- [ ] 嚎叫开始前击杀狗：不触发嚎叫；嚎叫开始后击杀：已激怒的蝗虫保持激怒，不撤销。
- [ ] 嚎叫期间狗仍可被武器击杀、接触玩家（按 01 的 200 伤害与死亡淡出）或被拉开 1600 脱战；嚎叫静音，无屏幕震动。
- [ ] 本票中间态：嚎叫结束后狗回到普通走路，不进入等待或自身激怒。
- [ ] 新增验收覆盖计时、离屏与暂停、普通/受伤/离屏/已激怒/后刷蝗虫、旧规则移除、击杀前后与中间态。
