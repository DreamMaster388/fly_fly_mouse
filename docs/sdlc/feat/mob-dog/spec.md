# Spec: 怪物狗与嚎叫激怒蝗虫

本规格部分取代 [angry-locust/spec.md](../angry-locust/spec.md)：蝗虫不再靠自身进入视野 3 秒自动激怒，改由狗的嚎叫触发；蝗虫激怒动画、激怒行走、激怒后的移速与爆炸、受伤不可激怒等契约继续有效。

## 问题

蝗虫的激怒现在完全自动发生，玩家没有一个可击杀、可躲避的“激怒源”，也没有优先集火的理由。中后期压力线性上升，缺少一个能改变当前战场节奏的精英事件；现有敌种里也没有狗。

## 方案

新增地面精英怪“狗”：从现有混刷中出现并走向玩家；进入视野一段时间后站定嚎叫，瞬间激怒当前视野内普通状态蝗虫；再经过等待和变身，以更高速度追击。蝗虫不再自行计时激怒，改由狗的嚎叫触发。狗在任意阶段接触玩家都会造成大量伤害并死亡；被武器击杀则有高额奖励。

## 用户故事

1. 作为玩家，我想要一种新的精英狗从刷怪节奏里出现，以便战场多一个优先处理目标。
2. 作为玩家，我想要狗进入视野后先走一段、再站定嚎叫，以便我能看懂它要做什么并决定集火还是拉开。
3. 作为玩家，我想要嚎叫瞬间把屏幕内普通蝗虫一起激怒，以便狗的存在直接改变当前战斗压力。
4. 作为玩家，我想要受伤蝗虫不被嚎叫激怒，以便先打伤蝗虫仍然是有效反制。
5. 作为玩家，我想要狗在嚎叫后还有等待和变身演出，再以明显更快的速度追击，以便高压阶段有明确的前摇和节奏。
6. 作为玩家，我想要狗在任何阶段碰到我都造成大量伤害并死亡，以便我不能贴着它硬扛。
7. 作为玩家，我想要击杀狗获得高额金币和经验，以便处理这个威胁有明确回报。

## 实现决策

- 接入现有敌人管理：与僵尸、蝗虫共用刷新环、寻路、地图速度倍率、物理分组、人口和既有脱战清理；显示高度 120，深度沿用地面敌人。狗没有受伤状态，受击只闪红。
- 混刷：沿用 2 秒刷新节拍，掷骰改为 10% 狗 / 20% 蝗虫 / 70% 僵尸；狗人口 3，同屏最多 1 只（按未销毁计）。人口满或无出生点时照常刷新失败。
- 阶段时间线：普通走路 60 → 首次进入视野计时 3 秒（离屏不暂停、不重置；场景暂停时不计）→ 站定播嚎叫约 2.7 秒 → 站定等 2 秒 → 站定播激怒动画约 4 秒 → 激怒行走 180（普通 60 的 3 倍）。嚎叫、等待、激怒动画期间位置固定；激怒行走按素材原生 24fps 循环，不额外倍速；地形减速继续叠加。
- 嚎叫结算：每只狗只触发一次，在嚎叫开始瞬间一次性结算，以当时玩家视野为准；只激怒身体中心在视野内、仍处于普通状态的蝗虫；受伤、离屏、已激怒或正在激怒的蝗虫不受影响，之后刷新或进入视野的蝗虫也不受影响。狗在屏外完成计时仍会嚎叫；嚎叫开始前死亡则无效果，开始后死亡不撤销已激怒。
- 蝗虫触发变更：删除原有自动计时激怒；其余激怒契约沿用旧规格。
- 接触：任意阶段接触玩家立即结算 200 伤害，狗死亡；不给击杀奖励、不爆炸、不留粘液；玩家生命归零照常结束本局。接触死亡优先于当前阶段。
- 武器击杀：100 HP，奖励 200 金 / 400 经验。
- 死亡表现：接触死亡与武器击杀都统一 0.3 秒淡出；没有死亡或受伤动画，也没有狗专属音效。嚎叫静音。
- 脱战：距离玩家超过 1600 时直接清理并释放人口，即使处于嚎叫或激怒动画中；小地图沿用现有红色敌人点，不做特殊标识。

## 测试决策

Seam：单一验收层，复用现有 Playwright 脚手架和真实 world 场景；复用 `spawnTestLocust` / `teleportPlayer` / `readTestLocust`，新增仅测试用的 `spawnTestDog` / `readTestDog`（与蝗虫同构），不新增生产接口。随机权重不直接测。

- 时间线：视野内生成狗，阈值前保持普通走路并位移；到点后按嚎叫→等待→激怒动画→激怒行走顺序推进，前三段位置固定，最后进入激怒速度追击，不跳步。
- 离屏与暂停：狗离开视野后计时继续，到点仍嚎叫；场景暂停期间计时不推进。
- 蝗虫联动：同屏普通蝗虫在嚎叫开始瞬间一起激怒；受伤、离屏、已激怒或正在激怒、嚎叫后刷出的蝗虫保持原状态。
- 旧规则移除：没有狗时，普通蝗虫在视野内停留超过原阈值仍不激怒。
- 接触：分别让处于普通、嚎叫、等待、激怒动画、激怒行走的狗接触玩家，断言固定大量伤害、狗死亡消失、无金币或经验、无爆炸或粘液；伤害使生命归零时进入结算界面。
- 击杀：武器打掉狗的全部生命，断言高额金币或经验；嚎叫前击杀不触发嚎叫，嚎叫开始后击杀不撤销蝗虫激怒。
- 刷新与人口：通过正常刷怪入口生成狗，断言人口占用、同屏第 2 只被拒；狗被击杀或脱战后可再刷出；超过既有脱战距离时即使处于嚎叫或激怒动画也会被清理。

不测：精确随机权重、帧号与帧序、动画素材、音效、小地图图标。

## 不在范围

- 狗的死亡动画、受伤动画、专属音效与粒子或屏幕震动。
- 小地图特殊图标、HUD 预警或狗血条。
- 多只狗同时存在、狗对其他敌种的增益、狗被其他敌人伤害。
- 蝗虫激怒系统重构、其他敌种复用狗嚎叫。
- 已定 HP、奖励、概率、伤害、速度之外的数值再平衡。
