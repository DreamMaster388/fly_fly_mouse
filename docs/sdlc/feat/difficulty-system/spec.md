# Spec: 逐档提升的游戏难度（来自 intent.md）
作者：lyd。状态：已批准。

一句话：局内每 30 秒升一档，7 档参数驱动僵尸、飞镖与计分，顶栏常驻显示档位名。

## 需求
R1 难度档由局内已用时间决定：每满 30 秒进一档，共 7 档，180 秒及以后恒为王者；档内参数不变。
R2 每档按 intent 表设置僵尸速度均值、场上同时上限、满血、击杀分与飞镖补速；难度表是这些数值的唯一来源。
R3 僵尸刷出时以当前档速度均值为均值、均值 20% 为标准差做高斯采样，低于 30 取 30，无上限；血量取当前档满血。已刷出的僵尸不随升档改变。
R4 场上僵尸数达到当前档上限时不再刷新，升档后按新上限判定；刷新节奏仍为每 2 秒尝试一次。
R5 飞镖补速随升档立即生效，按毫秒间隔换算（250、约 286、约 333、400、500、约 667、1000）；8 个槽位与消耗逻辑不变。
R6 击杀得分使用击杀发生时所在档的击杀分。
R7 顶栏左侧、时间下方常驻「难度 <档名>」，颜色随档：铜棕、银灰、金、翠绿、蓝、紫、红；其余 HUD 与结算不变。

## 风险与分歧
C1 旧僵尸是否随升档变强 → 已定：刷出时锁定（用户）。
C2 速度噪声参数 → 已定：σ=均值 20%，下限 30，无上限（用户）。
C3 档位显示位置与配色 → 本 spec 定：顶栏左侧时间下方，七色随档。
C4 3.5 支/秒等非整数补速 → 用毫秒间隔表达，允许小数延迟。

## 设计
- 新增难度模块，集中 7 档数据与「按已用时间取档」；WorldScene 每帧推进难度，档位变化时同步 HUD、僵尸刷新与飞镖补速。
- ZombieManager 每次生成按当前档快照创建僵尸，并用当前档上限做存活判定；生成间隔、刷点与接触逻辑不变。
- Zombie 改为接收刷出时的速度与血量快照，不直接读静态配置；受击、死亡动画与回调不变。
- WeaponOrbit 的补速定时器按档间隔重设，不重建槽位。
- 高斯采样用 Box–Muller 配 Phaser 随机源，不新增依赖。
- 僵尸速度、血量、上限与飞镖补速的静态默认值从 config 移入难度表，避免两处数值。
- Hud 增加档位文本；WorldScene 击杀计分改取当前档。

## 不在范围
- 胜利结算、难度选择、存档与数值再平衡。
- 僵尸互相碰撞、生成间隔随档变化。
