# 05: 粘液叠层与永久掉血

**要构建什么：** 玩家接触粘液即叠加永久掉血层数：同一片粘液 1 秒冷却，不同粘液共享层数；每层每秒扣 1 点生命，层数无上限且不会消退，直到本局重开。

**阻塞于：** 04（粘液生成与生命周期）。

**状态：** ready-for-agent

- [ ] 进入粘液立即叠 1 层；同一片 1 秒内不再叠加，满 1 秒可再次叠加；不同粘液按各自冷却触发并共享层数
- [ ] 每层每秒扣 1 点生命，层数线性叠加；0 层时不结算
- [ ] 粘液消失后层数与掉血效果保留，直到本局重开才清零
- [ ] 掉血时 HUD 血量同步变化，并出现每秒一次的轻微红闪
- [ ] 掉血致死触发本局结束；本局结束后不再触发粘液或结算掉血
- [ ] 新增验收覆盖：触发冷却、跨粘液叠层、持续掉血、粘液消失后保留、致死结束
