# 02: 蝗虫死亡动画接入

**要构建什么：** 蝗虫被武器击杀后播放完整的死亡动画（约 3 秒），不再是坠落淡出；尸体在动画期间不可碰撞、不可再被命中，击杀奖励与人口在死亡瞬间结算。

**阻塞于：** 01（重建浏览器验收基建）。

**状态：** ready-for-agent

- [ ] 武器击杀蝗虫后播放死亡精灵表的 37 帧动画（约 3 秒），只播一次，播完移除尸体
- [ ] 死亡瞬间停止移动与碰撞，尸体不可再被命中，也不造成任何伤害
- [ ] 击杀金币、经验与人口名额在死亡瞬间释放，不等待动画结束
- [ ] 死亡动画位置与蝗虫死亡位置一致，显示大小与站立时一致
- [ ] 新增验收覆盖：击杀触发死亡动画、帧序列推进到结束、奖励与人口即时释放、尸体清理
