# 01: 重建浏览器验收基建

**要构建什么：** 恢复现有验收套件共同依赖的浏览器辅助模块，让 `npm test` 重新可运行；新的蝗虫特性验收可以直接复用它打开世界、生成敌人、推进帧并读取场景状态。

**阻塞于：** 无（可立即开始）。

**状态：** ready-for-agent

- [ ] 现有全部浏览器验收套件在 `npm test` 下重新通过，不再因缺少公共辅助模块而报错
- [ ] 辅助模块提供各套件已依赖的能力：启动 Vite 与系统浏览器、开开始页并进入世界、生成/清空测试敌人、按帧推进、点击画布坐标、采集网络与控制台错误
- [ ] 浏览器与端口自动探测，不硬编码本机路径；端口被占用时可换端口
- [ ] 每个场景使用独立页面，结束后关闭页面、浏览器与 dev server，套件可重复运行
- [ ] 不新增生产依赖，游戏运行时行为与构建产物不受影响
