# 04: 粘液生成与生命周期

**要构建什么：** 蝗虫死亡动画播完后，在死亡位置留下一片循环播放的粘液，30 秒后淡出消失；粘液不阻挡移动、不占用人口、不参与战斗。

**阻塞于：** 02（蝗虫死亡动画接入）。

**状态：** ready-for-agent

- [ ] 只有死亡动画播完后才出现粘液，位置与死亡点一致
- [ ] 粘液循环播放粘液动画，整个过程不阻挡玩家与敌人移动
- [ ] 粘液存在 30 秒后淡出并被移除，不占人口、不参与命中判定
- [ ] 每只蝗虫死亡只生成一片粘液，粘液不随玩家远离而提前消失
- [ ] 新增验收覆盖：生成时机与位置、动画循环、到期移除、无移动阻挡
