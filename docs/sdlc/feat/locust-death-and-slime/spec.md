# Spec: 蝗虫死亡动画、爆炸与永久粘液掉血

一句话：蝗虫死亡统一播放 3 秒爆浆动画，爆开时伤害范围内的玩家，动画结束留下会持续掉血的粘液。

## 问题

蝗虫目前死亡只是 350ms 坠落淡出，自爆则瞬间消失、只扣 10 点，死亡位置没有任何后续压力。刚切好的死亡与粘液精灵表尚未接入，玩家也感知不到“杀死蝗虫后要避开现场”。

## 方案

- 所有蝗虫死亡（含接触自爆）统一走完整流程：死亡动画、延迟爆炸、留下粘液。
- 爆炸只伤玩家，有短暂延迟和固定范围，玩家可以及时跑开免伤。
- 自爆走同一流程，但不发放击杀奖励。
- 粘液留在地上并到期淡出、不挡路；同一片粘液对玩家有触发冷却。
- 每次触发叠 1 层永久掉血，层数越高掉血越快，且不会消退。

## 用户故事

1. 作为玩家，我想要蝗虫死亡有完整的爆浆动画，以便击杀有明确反馈。
2. 作为玩家，我想要死亡爆炸延迟一小会儿且范围有限，以便有反应时间而不是瞬间扣血。
3. 作为玩家，我想要被撞自爆的蝗虫也走同样流程，以便行为一致（只是不给我奖励）。
4. 作为玩家，我想要粘液留在地上，以便蝗虫死亡位置持续构成走位压力。
5. 作为玩家，我想要反复踩粘液会累积掉血，以便重复失误越来越疼。
6. 作为玩家，我想要掉血时有血条变化和红闪，以便知道自己在持续受伤。

## 实现决策

- 数值集中在蝗虫配置：死亡动画 37 帧、12fps；爆炸 20 点、半径 120、于死亡动画第 15 帧（约 1.25 秒）结算；粘液寿命 30 秒、触发冷却 1 秒；每层每秒 1 点、无层数上限。
- 每次死亡只结算一次爆炸，且只对玩家；不伤僵尸和其他蝗虫。玩家离开半径即免伤，这是有意保留的闪避窗口。
- 死亡动画期间尸体无碰撞、不可再被选中；死亡瞬间释放人口，武器击杀立即发放奖励；3 秒尸体与粘液不占人口。
- 自爆改为触发死亡流程，不再走旧的接触伤害路径，也不发放奖励。
- 粘液只在死亡动画播完后生成于死亡位置；不阻挡移动、不按距离清理，只按寿命淡出。
- 层数是全局累计值：不同粘液共享层数；粘液消失不清层；本局结束（含被掉血打死）后停止粘液触发与掉血结算。
- 掉血按固定每秒节拍结算，层数为 0 时不结算；扣血致死走现有结束流程。
- 表现层：不新增爆炸贴图，爆开视觉由死亡动画承担；死亡与粘液按现有蝗虫的显示比例接入；掉血反馈只做血条更新加每秒一次轻微红闪，不新增 HUD 元素。
- 资源：死亡与粘液各一套精灵表，帧尺寸分别为 456×260 与 392×90，由现有抽帧脚本产出。

## 测试决策

- 单一 seam：沿用浏览器黑盒验收（Vite dev server + `window.game`），只从场景/敌种状态与玩家血量断言。
- 前置：先恢复缺失的 `tests/helpers/harness.js`，现有验收套件都依赖它；不引入新的测试框架。
- 断言意图：
  1. 武器击杀后死亡动画播放并推进到结束；爆炸在配置帧结算，只命中半径内玩家并按配置伤害扣血，附近僵尸不掉血。
  2. 自爆没有即时接触伤害、没有击杀奖励，仍会爆炸并留下粘液，人口立即释放。
  3. 动画播完在原位置出现粘液；按配置寿命到期后消失（用可控时间推进，不真等 30 秒）。
  4. 接触粘液立即叠 1 层，配置冷却内不重复叠加，冷却结束再叠；另一片粘液按自己的冷却独立触发。
  5. 掉血速率随层数线性增加；粘液消失后层数保留并继续掉血；掉到 0 触发结束流程。
  6. HUD 血量与内部血量同步变化，掉血时出现红闪。
- 不测：像素级动画还原、音效、性能、真实 30 秒等待、多个蝗虫同时爆炸的时序细节。

## 不在范围

- 爆炸与粘液的音效、震屏、粒子等额外特效。
- HUD 层数图标、伤害飘字、状态栏。
- 僵尸或其他敌种的死亡流程与粘液。
- 粘液阻挡移动、影响寻路、按距离或数量上限清理。
- 爆炸、掉血、粘液时长之外的其他数值再平衡。

## 补充说明

- 术语见 `GLOSSARY.md`（死亡动画、爆炸、粘液、永久掉血、自爆）；无 ADR：这些是可回退的数值与流程取舍，不满足 ADR 门槛。
- 已知限制：无上限掉血最终必然致死，属于设计意图；自爆有明确的免伤窗口；粘液只按时间消失，玩家跑远后仍会保留到寿命结束。
