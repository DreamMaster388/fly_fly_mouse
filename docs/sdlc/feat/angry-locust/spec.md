# Spec: 蝗虫激怒与激怒蝗虫运动

## 问题

蝗虫从视野外刷出后只会匀速直冲，玩家看见它之后没有新的应对节点；移动、爆炸与落地残留从头到尾都是同一档，中后期蝗虫缺少压力升级。

## 方案

普通状态蝗虫第一次进入玩家视野后，经过 3 秒游戏时间永久激怒：先定身播一次变身动画，随后红眼行走，移速与行走动画播放速度都翻倍。激怒后的死亡爆炸更痛；数值上只改移动与爆炸。受伤先于激怒发生则本局永不激怒；一旦激怒，受伤状态不再覆盖。

## 用户故事

1. 作为玩家，我想要盯住一只蝗虫片刻后它明显变强，以便感受到逐步升级的压迫感。
2. 作为玩家，我想要激怒前有短暂的定身变身演出，以便判断哪只蝗虫正在升级。
3. 作为玩家，我想要红眼一旦出现就不会因掉血而退回，以便信任它的状态。
4. 作为玩家，我想要先打伤蝗虫就能阻止它激怒，以便有主动的反制手段。
5. 作为玩家，我想要激怒蝗虫的死亡爆炸更痛，以便更重视打断或远离它。

## 实现决策

- 视野判定用摄像机可视矩形覆盖蝗虫身体中心，不用与玩家的距离。
- 首次看见即开始计时，此后离开视野不暂停、不重置；场景暂停时计时随游戏时间停止。
- 仅普通状态（hp > 50% 且未受伤）可激怒。计时结束前进入受伤状态，计时作废，本局永不激怒。
- 激怒是终态：之后 hp ≤ 50% 不切受伤动画，也不应用受伤加速；维持激怒档的移动、动画与爆炸。
- 触发即定身，一次性激怒动画按原速播放，不随激怒行走加速；期间仍可受伤、被击杀，玩家接触仍会自爆；死亡流程优先并打断变身。
- 变身结束切激怒行走；地形速度倍率继续叠加；显示高度不变。
- 激怒死亡爆炸 40，普通 20，武器击杀与接触自爆共用；半径、延迟、只伤玩家沿用现有契约。
- 激怒不改变粘液的生成、叠层、每层伤害与触发冷却。
- 每只蝗虫只激怒一次。

## 测试决策

Seam：现有 Playwright 验收脚手架 + 真实 world 场景；复用 `spawnTestLocust` / `teleportPlayer` / `readTestLocust` / `callTestLocust`，不新增生产接口；必要时只给测试读取器补 `enraged`、`animTimeScale` 字段。

- 视野与计时：视口内生成普通蝗虫，3 秒阈值前仍未激怒；阈值到点开始定身变身，约 5 秒内进入激怒行走。把玩家移开使蝗虫离屏，到点仍会激怒。
- 状态排斥：先打至受伤再等过阈值，始终不激怒；从未进入视野的普通蝗虫不激怒。
- 终态：变身中或播完后打至受伤血量，仍完成变身并以激怒档维持动画、速度与爆炸。
- 变身：触发后位置保持、播放一次性激怒动画，播完切激怒行走；变身中击杀进入死亡流程。
- 速度与动画：同一地形下，激怒后的位移速率与行走动画速率相对普通状态翻倍。
- 爆炸：激怒蝗虫被击杀与接触自爆都按激怒值结算；范围外玩家不受影响。
- 粘液：激怒死亡仍留下粘液，首次触碰的叠层行为不变。

不测：具体帧号与帧序、动画素材本身、配置字段名、音效。

## 不在范围

- 受伤蝗虫的激怒或恢复。
- 其他敌种（如狗）的激怒复用。
- 激怒音效、粒子、屏幕震动。
- 激怒蝗虫的奖励、人口或刷怪概率调整。
- 激怒状态的小地图或 UI 标识。

## 补充说明

术语见 [GLOSSARY.md](../../../../GLOSSARY.md) 的「视野」「激怒」「激怒动画」「激怒行走」。无 ADR：设计可逆，且不需要背景才能理解。

已知限制：计时开始后不暂停，蝗虫可能在离屏时完成激怒，玩家回屏会直接看到红眼状态；这是刻意选择。
