# 02: 激怒蝗虫的移动

**要构建什么：** 激怒行走阶段的移速与动画播放速率都相对普通状态翻倍，并继续叠加地形速度倍率；激怒后再受伤也不降档，不应用受伤加速。

**阻塞于：** 01（激怒触发与变身演出）。

**状态：** ready-for-agent

- [ ] 变身结束后使用激怒行走，同一地形下的实际移速为普通蝗虫的 2 倍。
- [ ] 激怒行走动画以普通行走的 2 倍速率播放，帧序列保持循环。
- [ ] 激怒蝗虫经过地形速度倍率时，2 倍速与地形倍率叠加。
- [ ] 激怒后 hp 降到 50% 及以下，仍保持激怒移速与动画，不应用受伤状态的 1.2 倍加速。
- [ ] 新增验收覆盖同地形速度对比、动画速率对比、地形叠加与受伤后不降档。
