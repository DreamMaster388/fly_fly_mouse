# 03: 激怒死亡爆炸

**要构建什么：** 激怒蝗虫死亡爆炸对范围内玩家造成 40 伤害，武器击杀与接触自爆共用；普通蝗虫仍为 20；爆炸半径、延迟、只伤玩家以及死后的粘液流程保持不变。

**阻塞于：** 01（激怒触发与变身演出）。

**状态：** ready-for-agent

- [ ] 武器击杀激怒蝗虫，约 625ms 后对 120 范围内的玩家造成 40 伤害；范围外玩家不受伤。
- [ ] 激怒蝗虫接触玩家自爆，爆炸同样造成 40 伤害；不给击杀奖励，人口名额即时释放。
- [ ] 普通蝗虫被击杀或接触自爆仍造成 20 伤害。
- [ ] 爆炸仍只作用于玩家，不伤害僵尸或其他蝗虫。
- [ ] 激怒蝗虫死亡仍按原延迟留下粘液；粘液的触发冷却、叠层与每层每秒伤害不变。
- [ ] 新增验收覆盖击杀/自爆 40、普通仍 20、范围外免疫与粘液回归。
