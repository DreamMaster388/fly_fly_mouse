# 01: 激怒触发与变身演出

**要构建什么：** 普通状态蝗虫首次进入玩家视野 3 秒游戏时间后定身播放一次激怒动画，随后进入激怒行走；离开视野不暂停计时，受伤先到或从未入屏则本局不激怒；变身期间仍可受伤、被击杀或被接触自爆，死亡流程会打断变身；激怒为终态，之后不再切受伤动画。

**阻塞于：** 无（可立即开始）。

**状态：** ready-for-agent

- [ ] 视口内出现的普通蝗虫，3 秒前保持普通行走；3 秒到点开始定身变身，变身动画按原速播放一次，约 1.7 秒后进入激怒行走。
- [ ] 首次看见后把玩家移开使蝗虫离屏，3 秒到点仍开始变身，不因离屏暂停或重置计时。
- [ ] 打开商店等场景暂停期间计时不推进，恢复后从暂停处继续。
- [ ] 计时结束前 hp 降到 50% 及以下，则本局不再激怒；从未进入视野的普通蝗虫同样不激怒。
- [ ] 变身期间位置不变；仍可被武器命中、被击杀，玩家接触仍触发自爆；死亡流程会打断变身。
- [ ] 激怒后再降到 50% 及以下，不切换到受伤动画；每只蝗虫只触发一次激怒。
- [ ] 变身动画与激怒行走的显示高度与普通蝗虫一致，不因更换精灵表改变大小。
- [ ] 新增验收覆盖上述计时、状态排斥、变身定身、终态与显示尺寸行为。
