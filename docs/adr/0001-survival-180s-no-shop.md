# ADR 0001：生存 180 秒定胜负，商店体系整体下线

- 状态：已接受
- 日期：2026-11-22
- 决策者：lyd

## 决策

游戏目标改为存活 180 秒：世界场景创建后累计 180 秒游戏时间，HUD 以 3:00 倒计时显示，归零判胜；生命先归零判负，同帧死亡优先判负。难度段位整体删除，敌人强度沿用现有固定混刷。商店、金币经济、饰品/红宝石与相关 HUD 入口（金币按钮、饰品栏、右侧面板）整体下线。蹦蹦炸弹的配置、`BombWeapon`、资源与内部挂载方法保留，但不提供任何玩家或开发控制台获取入口。

## 理由

商店下线后金币失去用途，保留只会留下不可消费的死 UI；3 分钟单局用经验/升级点驱动飞镖成长已足够。炸弹实现保留，是为未来的获得方式留资产，而不是当前玩法的一部分。

## 后果

旧难度、商店、金币相关验收与规格冻结，由新规格取代；`mountWeapon('bomb')` 仅作为内部/验收入口；玩家与开发控制台都无法获得炸弹。
